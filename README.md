# ねつとすがた ― 融点・沸点を見つけよう(試作版)

中学1年生が「状態変化と熱」、特に **融点・沸点** を理解するためのブラウザゲーム。
物質を温めたり冷やしたりしたときの温度のグラフを4択で予想し、実験シミュレーション(粒子モデルつき)で答え合わせして、
グラフの平らな部分から融点・沸点を読み取る。設計書は `docs/design.html`。

## 遊び方

**ブラウザで遊ぶ:** https://transpason.github.io/game_heat_curve_quiz/ (設計書: https://transpason.github.io/game_heat_curve_quiz/docs/design.html)

`index.html` をブラウザで開くだけでも動く(サーバー・インストール不要、外部ライブラリなし)。縦向き・横向きのどちらでも遊べる。

1. **お題**を読む(物質・量・火の強さ・はじめの温度)
2. **予想**: 4つのグラフから選ぶ(☆1)
3. **実験**: グラフが伸び、左のビーカーで粒子が動く。終わったあとはグラフをタップすると、その時間の粒子のようすが見られる
4. **読み取り**: 平らな部分をタップ →「融点/沸点」と温度(±ボタン)を答える。誤差±2℃まで正解(☆2)
5. **ふりかえり**: 選択問題1問(☆3)

| ステージ | 内容 |
| --- | --- |
| 1〜3 | 氷をとかす / 水を沸騰させる / 氷から沸騰まで(本当の比率のグラフも紹介) |
| 4・5 | 量を2倍 / 強火 → 平らな部分の長さは変わるが、融点は変わらない |
| 6 | 水をこおらせる(冷やしても0℃で平ら) |
| 7・8 | パルミチン酸(融点約63℃) / エタノール(沸点約78℃) |
| 応用A・B | なぞの物質の融点・沸点を測って、物質カードから正体を当てる(☆1 読み取り、☆2 正体当て、☆3 ふりかえり) |
| おまけ | 水とエタノールの混合物(はっきり平らにならない) |

測った融点・沸点は **図鑑** にたまり、温度スライダーでその温度での状態(固体・液体・気体)を確かめられる。

## 構成

- `index.html` / `style.css` — 画面(上部、実験・グラフ・下のパネル、タイトル・ステージ選択・図鑑)
- `js/thermo.js` — 加熱・冷却のシミュレーション、ステージ定義、4択の不正解グラフ、採点(DOM に依存しない純粋な関数。Node からテスト可能)
- `js/game.js` — ステージの進行、入力、Canvas 描画(粒子モデル・グラフ・図鑑)、localStorage への保存
- `docs/design.html` — ゲーム設計書
- `tests/thermo.test.js` — シミュレーションと採点のテスト

node --test tests/*.test.js
