概要

融点と沸点がわかるようになるためのステージ制ゲーム。物質を温めたり冷やしたりしたときの温度のグラフを4つの中から予想して選び、 実験シミュレーションで答え合わせする。そのあと結果のグラフから融点・沸点を自分で読み取る。 グラフが平らな間は粒子モデルが「状態が変わっている途中」のようすを見せるので、 「融点・沸点 = 状態が変わる温度。変わっている間は温度が上がらない」ことを目で確かめられる。

項目内容
対象中学1年生(理科「身のまわりの物質 ― 状態変化」)。授業・家庭学習の両方
形式ステージ制(本編8 + 応用2 + おまけ1)。1ステージ2〜3分。☆1〜3で評価
端末学校配布のタブレット・Chromebook、PC(ブラウザ)。縦・横の両方に対応
遊び方の核お題を読む → グラフを4択で予想 → 実験で答え合わせ → 融点・沸点を読み取る → ふりかえり1問
技術HTML + JavaScript + Canvas、外部ライブラリ・ビルドなし(レンズ・シューターと同じ)

学習目標

プレイ後に次の4点を説明できる状態を目指す。

  1. 融点は固体がとけて液体になる温度、沸点は液体が沸騰して気体になる温度。温度のグラフでは平らな部分として表れる
  2. 状態が変わっている間は、加熱し続けても温度は上がらない。加えた熱は粒子の並び方を変える(状態を変える)のに使われる
  3. 融点・沸点は物質ごとに決まっている。量や火の強さを変えても変わらない(変わるのは平らな部分の長さ)。だから融点・沸点で物質を見分けられる
  4. 融点・沸点がわかれば、ある温度でその物質が固体・液体・気体のどれかを判断できる(融点より低い→固体、融点と沸点の間→液体、沸点より高い→気体)

粒子の数が変わらない(質量は変わらない)ことは画面に「質量 100g」を出し続けて伝えるが、主なねらいからは外す。

1ステージの流れ

段階画面で起きることねらい
① お題実験の条件をカードで提示。例:「−20℃の氷 100g を弱火で加熱。10分間はかる」条件(物質・量・火力・初めの温度)を読む
② 予想4つのグラフから「こうなる」と思うものを選ぶ(下図)知識を使って先に考える
③ 実験左でビーカー・温度計・粒子モデルが動き、右のグラフに本物の線が伸びる。選んだグラフは点線で重ねる。平らな部分では「熱は状態を変えるのに使われています」の吹き出し温度が止まる理由を粒子で見る
④ 読み取り結果のグラフの平らな部分をタップ →「これは融点? 沸点?」と「何℃?」を答える(温度は目盛りから読む。±2℃で正解)。答えた種類と温度がグラフのどれかの平らな部分と合えば正解(タップした部分と別でもよい)。不正解のときは「種類がちがう/温度がずれている/平らな部分がある・ない」の理由と自分の答えを表示融点・沸点をグラフから見つける
⑤ ふりかえり☆評価、選んだグラフが違った場合はどこが違ったかの解説、最後に選択問題を1問理由を言葉で選べるようにする

4ステージ1の氷を2倍の量に平らな部分は長くなるが、融点は0℃のまま

640℃の水を冷却(凍るまで)冷やすときも0℃で平ら(液体→固体も融点と同じ温度)
7固体のパルミチン酸を加熱物質が変われば融点も変わる(約63℃)
8液体のエタノールを湯せんで加熱沸点は約78℃。水の100℃と比べる
応用Aなぞの固体Xを湯せんで加熱して融点を測り、物質カードから正体を当てる(答え:ナフタレン 約81℃)融点で物質を見分けられる
応用Bなぞの液体Yを湯せんで加熱して沸点を測り、正体を当てる(答え:メタノール 約65℃)沸点で物質を見分けられる
おまけ水とエタノールの混合物を加熱混合物は温度がはっきり平らにならない(決まった沸点がない)

「沸騰の平らな部分」は見やすさ優先で短く描く(実際は融解の約7倍の熱が要る)。ステージ3のふりかえりで「本当はもっと長い」と、実際の比率のグラフを並べて紹介する。

融点・沸点の図鑑

ステージをクリアするたびに、測った物質の融点・沸点を記録する。物質ごとに1行、温度の数直線の上で固体(青)・液体(緑)・気体(橙)の範囲を色分けして並べる。まだ測っていない値は「?」。応用ステージでは図鑑と物質カードをヒントに使える。

シミュレーションの考え方

  • 一定の火力で熱を加え続ける。状態変化していない間は温度が上がり、融点・沸点に達すると、物質全体が変わり終わるまで温度は一定。量を2倍にすると平らな時間も2倍、火力を2倍にすると半分になる。
  • 沸騰の平らな部分の長さは見やすさ用に短縮する(ステージ3の紹介画面だけ実際の比率)。
  • 粒子モデル:固体 = 規則正しく並んで小さく振動、液体 = くっついたまま動き回る、気体 = 速く飛び回り間隔が広い。状態変化中は2つの状態が混ざって描かれる。熱はビーカーの底と横の壁から出入りするので、とけるのもこおるのも固体のかたまりの底・横の外側から(上の面は空気に触れているだけなので最後)。
  • 計算は js/thermo.js(DOMに依存しない純粋関数)にまとめ、node --test でテストする。4択の不正解グラフもここで条件から生成する。
